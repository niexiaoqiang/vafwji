# 皮肤制作指南

炸飞机支持可选皮肤：玩家点顶栏的「🎨 皮肤」即可切换，选择会自动保存。皮肤**只改变颜色、字体、图标和少量特效**，不会改变布局和操作，所以任何皮肤下按钮位置、玩法都完全一样。

## 三步做一套新皮肤

1. **复制模板**：把 `src/skins/_template.js` 复制为 `src/skins/<皮肤id>.js`（例如 `sakura.js`），修改 `id`、`name`、`author`、`description`，再按下面的变量表改配色。
2. **检查**：运行 `npm run skins:check`。它会检查必填项、取值格式、id 是否重复，并提示对比度不足（看不清）的颜色组合。有错误的皮肤不会出现在游戏里。
3. **预览**：运行 `npm run skins:preview`，用浏览器打开生成的 `dist/skins-preview.html`，所有皮肤的电脑端对局和手机端大厅并排对比。也可以 `npm run start` 后在游戏里直接切换查看。

`src/skins/` 下的文件放进去就会自动出现在皮肤列表里，不需要改其他代码。文件名以 `_` 开头的（比如模板）不会被加载。重新构建、部署后玩家就能选到。

## 皮肤文件结构

```js
export default {
  id: 'sakura',              // 小写字母、数字、连字符，2～32 位，不能和已有皮肤重复
  name: '樱花',               // 显示在皮肤列表里
  author: '你的名字',
  description: '一句话介绍',
  mode: 'light',             // dark 或 light：决定“跟随系统”时用哪套，以及浏览器控件的深浅
  order: 10,                 // 选填：列表中的排序，数字小的在前
  tokens: { /* 全部样式变量，见下表，一个都不能少 */ },
  icons: { hit: '✕', sink: '✹' },          // 选填
  effects: { glow: false, paper: true },  // 选填
  extraCss: '',              // 选填：少量补充样式，见文末
};
```

## 样式变量 `tokens`（全部必填）

取值规则：
- **颜色**：`#rgb`、`#rrggbb`、`#rrggbbaa`、`rgb()`、`rgba()`、`hsl()`、`hsla()` 或 `transparent`。
- **颜色或渐变**：颜色，或 `linear-gradient(...)` / `radial-gradient(...)` / `conic-gradient(...)`。
- **长度**：`px` 或 `rem`，如 `12px`。
- **字体**：字体栈。微应用不能加载外部字体，只能用系统里已有的字体。
- **阴影**：CSS `box-shadow` 的值，不需要就写 `none`。
- 不允许出现 `url(...)`、分号、花括号等内容（防止引用外部资源或注入样式）。

### 页面与卡片

| 变量 | 类型 | 用在哪里 |
| --- | --- | --- |
| `bg` | 颜色或渐变 | 页面背景，可以是纯色或渐变 |
| `surface` | 颜色 | 卡片、弹窗背景 |
| `surface-2` | 颜色 | 卡片内的次级块：输入框、列表项、分段按钮底色 |
| `line` | 颜色 | 边框、分隔线 |
| `overlay` | 颜色 | 弹窗后面的遮罩 |
| `shadow` | 阴影 | 卡片阴影 |

### 文字

| 变量 | 类型 | 用在哪里 |
| --- | --- | --- |
| `text` | 颜色 | 正文与标题 |
| `text-dim` | 颜色 | 说明文字、坐标、次要信息 |

### 强调与按钮

| 变量 | 类型 | 用在哪里 |
| --- | --- | --- |
| `accent` | 颜色 | 主按钮、选中状态、轮到你的提示 |
| `accent-ink` | 颜色 | 主按钮上的文字（要和 accent 有足够对比） |
| `accent-2` | 颜色 | 辅助强调色：倒计时进度条渐变的另一端、链接 |
| `glow` | 阴影 | 主按钮的光晕 / 阴影，不需要就写 none |

### 提示色

| 变量 | 类型 | 用在哪里 |
| --- | --- | --- |
| `success` | 颜色 | 已准备、胜利、在线 |
| `warning` | 颜色 | 倒计时紧急、掉线提醒 |
| `danger` | 颜色 | 退出、失败、被击落 |

### 棋盘

| 变量 | 类型 | 用在哪里 |
| --- | --- | --- |
| `enemy-cell` | 颜色 | 对方棋盘的格子 |
| `enemy-line` | 颜色 | 对方棋盘的格线（格子之间的缝） |
| `mine-cell` | 颜色 | 我的棋盘的格子（布阵页也用它） |
| `mine-line` | 颜色 | 我的棋盘的格线 |
| `grid-gap` | 长度 | 格子之间的缝宽，纸面风可以设为 0px 配合虚线 |
| `cell-radius` | 长度 | 格子圆角 |

### 飞机

| 变量 | 类型 | 用在哪里 |
| --- | --- | --- |
| `plane-1` | 颜色 | 一号机颜色（机头用原色，机身自动调淡） |
| `plane-2` | 颜色 | 二号机颜色 |
| `plane-3` | 颜色 | 三号机颜色 |
| `head-dot` | 颜色 | 机头上的圆点 |

### 攻击结果

| 变量 | 类型 | 用在哪里 |
| --- | --- | --- |
| `miss` | 颜色 | 未命中的空心圈 |
| `hit` | 颜色 | 命中机身的符号 |
| `hit-bg` | 颜色 | 命中格的底色 |
| `sink` | 颜色 | 击落（打中机头）格的底色 |
| `sink-ink` | 颜色 | 击落格上的符号 |
| `wreck` | 颜色 | 已击落飞机的残骸格 |
| `mark` | 颜色 | 玩家自己的猜测标记（虚线） |
| `latest` | 颜色 | 最近一次攻击的描边 |

### 形状与字体

| 变量 | 类型 | 用在哪里 |
| --- | --- | --- |
| `radius` | 长度 | 卡片圆角 |
| `radius-sm` | 长度 | 按钮、输入框圆角 |
| `font` | 字体 | 正文字体栈（只能用系统字体，微应用不能加载外部字体） |
| `font-title` | 字体 | 标题字体栈 |

### 图标 `icons`（选填）

| 名称 | 默认 | 说明 |
| --- | --- | --- |
| `miss` | （空） | 未命中（留空 = 空心圈） |
| `hit` | `✕` | 命中机身 |
| `sink` | `✹` | 击落 |
| `mark` | `?` | 猜测标记 |

### 特效 `effects`（选填）

| 名称 | 默认 | 说明 |
| --- | --- | --- |
| `glow` | false | 命中、击落、主按钮发光 |
| `radar` | false | 对方棋盘中心的雷达光晕、大厅卡片上的雷达圈 |
| `paper` | false | 页面横线纸纹理 |
| `dashedGrid` | false | 格子用虚线描边（通常配合 grid-gap: 0px） |
| `pulse` | true | 最近一次攻击的闪动圆圈 |


## 配色建议

- **三架飞机的颜色要彼此区分明显**，并且和 `mine-cell` 有足够对比；机身会自动用飞机颜色和格子颜色混合调淡，机头用原色加 `head-dot` 圆点。
- **对方棋盘和我的棋盘最好用不同的色调**（比如雷达绿对夜空蓝），玩家一眼就能分清在看哪一块。
- `hit`、`sink`、`miss` 要在 `enemy-cell` 上清楚可见；`npm run skins:check` 会提示对比度不足的组合。
- 深色皮肤的 `accent-ink`（主按钮文字）一般用深色，浅色皮肤一般用白色。
- 纸面、虚线风格：`grid-gap` 设为 `0px`、`cell-radius` 设为 `0px`，再打开 `effects.dashedGrid`。

## 补充样式 `extraCss`（尽量少用）

变量覆盖不到的细节可以写少量 CSS。规则：
- 每条选择器都要以 `[data-skin="<你的id>"]` 开头，只对自己的皮肤生效，例如：
  ```js
  extraCss: '[data-skin="sakura"] .brand-name { letter-spacing: 4px; }',
  ```
- 不能使用 `url(...)` 和 `@import`。
- **不要改尺寸、位置、显示隐藏**，否则可能破坏手机布局；页面的类名也可能随版本调整，补充样式不保证长期有效。

## 微应用里的注意事项

- 不能加载外部图片、字体和样式，皮肤里也不要引用。
- 玩家的皮肤选择保存在社区存储里（需要 `storage.read` / `storage.write` 权限，已在 manifest 中申请）。
